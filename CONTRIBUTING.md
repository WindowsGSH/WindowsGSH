# Contributing to WindowsGSH

Thank you for helping improve WindowsGSH.

Before opening an issue or pull request, read the
[Contributing guide](https://github.com/WindowsGSH/WindowsGSH/wiki/Contributing).
It covers bug reports, feature requests, development setup, testing, pull
requests, module contributions, and the project's source-available licence.

Security vulnerabilities must be reported privately as described in the
[Security Policy](SECURITY.md), not through a public issue.

By participating in this project, you agree to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).
